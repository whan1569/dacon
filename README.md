# 신용카드 고객 세그먼트 분류 AI 경진대회

## 프로젝트 개요
이 프로젝트는 신용카드 고객의 다양한 금융 활동 데이터를 분석하여 고객 세그먼트를 예측하는 AI 모델을 개발합니다.

## 평가 지표
- Macro F1-Score
- Public Score: 전체 테스트 데이터 중 50%
- Private Score: 전체 테스트 데이터 중 100%

## 프로젝트 구조
```
.
├── data/                    # 데이터 디렉토리
│   ├── train/              # 학습 데이터 (201807 ~ 201812)
│   │   ├── 1.회원정보/     # 회원 기본 정보
│   │   ├── 2.신용정보/     # 신용 관련 정보
│   │   ├── 3.승인매출정보/ # 승인 및 매출 정보
│   │   ├── 4.청구정보/     # 청구 관련 정보
│   │   ├── 5.잔액정보/     # 잔액 관련 정보
│   │   ├── 6.채널정보/     # 채널 이용 정보
│   │   ├── 7.마케팅정보/   # 마케팅 관련 정보
│   │   └── 8.성과정보/     # 성과 관련 정보
│   └── test/               # 테스트 데이터
├── main.py                 # 메인 실행 파일
├── feature_engineering.py  # 특성 엔지니어링 모듈
├── check_columns.py       # 데이터 컬럼 확인 스크립트
├── check_credit.py        # 신용정보 확인 스크립트
├── data_dictionary.md     # 데이터 사전
├── requirements.txt       # 필요한 패키지 목록
└── README.md             # 프로젝트 설명 문서
```

## 설치 방법
1. 필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

## 실행 방법
```bash
python main.py
```

## 주요 기능
1. 데이터 로드 및 전처리
   - parquet 형식의 데이터 파일 로드
   - 결측치 처리
   - 데이터 타입 변환 (ID, 연령 등)
   - 특성 엔지니어링

2. 특성 엔지니어링
   - 회원정보 기반 특성
   - 신용정보 기반 특성
   - 승인매출정보 기반 특성
   - 청구정보 기반 특성
   - 잔액정보 기반 특성
   - 채널정보 기반 특성
   - 마케팅정보 기반 특성
   - 성과정보 기반 특성

3. 모델 학습
   - LightGBM 모델 사용
   - Optuna를 통한 하이퍼파라미터 최적화
   - 5-fold Cross Validation
   - Macro F1-Score 기반 평가

4. 예측 및 제출
   - 테스트 데이터에 대한 예측
   - submission.csv 파일 생성

## 개발 환경
- Python 3.8+
- 주요 라이브러리:
  - pandas
  - numpy
  - scikit-learn
  - lightgbm
  - optuna
